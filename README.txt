# Conexão Segura — HTML, CSS e JavaScript

Versão convertida do projeto React/TypeScript para JavaScript puro.

Arquivos:
- index.html
- style.css
- script.js
- assets/ (avatares e moeda)

Como executar:
1. Extraia a pasta.
2. Abra o arquivo index.html no navegador.
3. Não precisa instalar Node, React ou TypeScript.

O projeto mantém:
- jogo de cartas de segurança digital;
- 5 fases com 10 cartas cada (50 cartas), com dificuldade crescente: perguntas mais sutis, tempo para responder a partir da fase 3 (25s, 20s, 15s) e mais moedas por acerto;
- explicação após cada resposta; ao perder todas as vidas, recomeça só a fase atual;
- 7 vidas (cartas e Corrida da Bolha) e moedas;
- seleção de avatar e nickname;
- armazenamento do jogador na sessão;
- sons;
- Corrida da Bolha;
- obstáculos, moedas, vidas e vitória aos 5000 m;
- dificuldade progressiva: 5 níveis de 1000 m (mais velocidade, obstáculos mais frequentes e em dupla a partir do nível 3);
- visual com orbes desfocadas no fundo e fontes Baloo 2 + Nunito (carregadas do Google Fonts; sem internet usa fonte do sistema);
- recorde salvo no navegador.
- tela de Créditos no menu inicial.

Logo da tela de Créditos:
assets/cruzeiro-do-sul-logo-branco.png (versão branca para fundo escuro), assets/cruzeiro-do-sul-estrela.png (marca d'água do fundo) e assets/cruzeiro-do-sul-logo.png (cores originais, fundo transparente).
